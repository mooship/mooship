# Hi, I'm Timothy 👋

Software developer from Pretoria, South Africa, guided by leftist values. I build full-stack web applications and open-source tools, mostly in TypeScript, with a growing interest in maps and open data.

## What I'm working on

- [**MapCairn**](https://github.com/MapCairn/mapcairn): an open-source React SDK for map applications that need to be accessible and private, built on MapLibre GL JS. [Try the playground](https://mapcairn.timothybrits.co.za/map).
- [**geolint**](https://github.com/MapCairn/geolint): a linter for GeoJSON. It catches swapped latitude and longitude, wrong projections, bad ring winding, self-crossing polygons and other mistakes that schema validation misses.
