## Things I've built

- [**Fieldnotes**](https://github.com/mooship/fieldnotes): my personal site and blog, and an open, self-hosted Linktree alternative. Astro + TypeScript.
- [**Focal**](https://github.com/mooship/Focal): an iOS task manager for ADHD. One task at a time, no lists, no decisions. Swift.
- [**Lights On, Garsfontein?**](https://github.com/mooship/lights-on-garsfontein): a volunteer-run power outage tracker for my neighbourhood. SolidJS + Cloudflare Workers + D1.
- [**Cuba Action Desk SA**](https://github.com/mooship/cubaactiondesk): a place for South Africans who want to act, learn and give in response to the US blockade of Cuba.
